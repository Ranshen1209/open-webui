# Slim Sakrylle Web for 2c2g — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cut Sakrylle Web's backend resident RAM from ~1.4 GB to ~500-600 MB and Docker image from ~6 GB to ~2.5 GB, by gating router registration, dropping unused heavy dependencies, and hiding their frontend entry points — without losing chat, OIDC, admin, Memories/Notes/Calendar/Channels/Automations, Tools/MCP, or remote-proxy image/audio.

**Architecture:** "Build-time prune + route gating" (Approach B in the spec). Move `routers/retrieval` and `routers/ollama` imports inside `if SAKRYLLE_ENABLE_*_ROUTER:` blocks in `main.py` so their transitive heavy chain (torch, sentence-transformers, chromadb, playwright) never loads. Flip a handful of backend defaults so an un-configured deployment lands in slim mode. Strip the 16 packages from `requirements.txt`. On the frontend, drop `pyodide:fetch` from the production build and surface gating booleans through `/api/config` so existing components hide their entry points.

**Tech Stack:** FastAPI + SvelteKit. Python 3.12, Node 18.x-22.x. Dev runtime managed via `uv` in `.venv/`. Spec: `docs/superpowers/specs/2026-06-11-slim-for-2c2g-design.md`.

The server build runs the "slim" profile: RAG, in-app web search, code
